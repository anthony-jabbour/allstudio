# Desktop S0 Implementation Plan

> **For agentic workers:** execute inline using superpowers:executing-plans. Founder requested implementation by this agent in the active checkout.

**Goal:** run and package a hardened Electron window using the existing editor, with executable IPC/isolation proof.
**Architecture:** main owns app assets and typed IPC, preload exposes one runtime-information request only to the main frame, renderer imports the existing editor shell. No project execution or filesystem API in S0.
**Tech Stack:** approved Electron 45.0.0, electron-vite 6.0.0, electron-builder 26.18.0, Playwright 1.64.1; existing React/Vite/TypeScript.
**Spec:** docs/research/phase-02-desktop.md and founder approval in chat, 2026-10-25.

## Review Focus

- An iframe trying to call native IPC must be denied, including a same-origin subframe.
- Renderer navigation and popups must not reach external content with preload privileges.
- Asset paths must remain within the packaged renderer directory.
- A packaged binary must launch without the repository development server.
- Runtime methods must reject unexpected arguments and untrusted senders.
