# Contributing

allstudio is not yet open for external contribution. This file exists so the public repository states its current rules.

1. Read `AGENTS.md`, `CLAUDE.md`, and the active section of `RoadMap.md`.
2. Treat `CODEBASE_ARCHITECTURE.md` and `REPOSITORY_ARCHITECTURE.md` (v0.2) as the architecture source of truth when older drafts disagree.
3. Do not start Phase 1+ work until Phase 0 Onlook validation has evidence.
4. Do not add Electron, `packages/protocol`, Clerk, Stripe, or private cloud code here unless the founder approves that slice.
5. Ask before adding a new open-source dependency. New tools need a verified GitHub star count of at least 1,000, a compatible license, and a real fit.

The next engineering milestone is **Phase 0: reproduce and validate Onlook's source-editing behavior**.
