# nested-components-fixture ("Lumen Notes")

Phase 1 source-editing fixture: Next.js App Router, React, TypeScript, and Tailwind CSS.

It exercises nested components across files, a component reused twice
(`NavLink`), a `.map()` list (`NoteCard`), a ternary and a `&&` conditional,
and text that mixes expressions with static text. It is a test fixture, not a
product or design template.

From the public repository root:

```bash
bun --filter @allstudio/nested-components-fixture dev
```
