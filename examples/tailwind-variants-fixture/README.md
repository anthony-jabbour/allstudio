# tailwind-variants-fixture ("Harbor Studio")

Phase 1 source-editing fixture: Next.js App Router, React, TypeScript, and Tailwind CSS.

It exercises responsive (`sm:`/`md:`/`lg:`), state (`hover:`/`focus-visible:`)
and `dark:` variants, a small `cn()` class helper, a template-literal
`className`, and a `components/` + `lib/` layout. It is a test fixture, not a
product or design template.

From the public repository root:

```bash
bun --filter @allstudio/tailwind-variants-fixture dev
```
